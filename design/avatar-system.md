## หลักการ

1. **ตัวฐานเดียว ท่าทางชุดเดียว**: ทุกชิ้น (หน้า ผม เสื้อผ้า) ใส่บนตัวฐาน Autosprite ตัวเดียว ชิ้นจึงผสมกันได้ทุกแบบ และไม่ต้อง gen ใหม่เมื่อเพิ่มชุด
2. **ห้ามหมุนหรือบิด pixel art**: อะไรที่ขยับ (กะพริบตา ผมพลิ้ว ชายกระโปรง) วาดเป็นหลายท่าไว้ก่อน แล้วให้เวลาหรือสปริงเป็นตัวเลือกท่า
3. **วาดเป็นสีเทา เกมย้อมสีเอง**: ชิ้นเดียวได้ทุกสี เพราะเกมย้อมตามความสว่างเดิม แสงเงาจึงยังอยู่
4. **ข้อมูลอยู่ใน `shared/`**: ชิ้นส่วนอยู่ใน `shared/parts.json` ชนิดเสื้อผ้าและสีอยู่ใน `shared/avatar.ts` server ตรวจ look ได้ก่อนส่งให้ผู้เล่นคนอื่น

## ชิ้นซ้อน (`shared/parts.json`)

```json
{"id":"pony_tail","slot":"hairBack","tint":"hair","anchor":"head",
 "sway":{"poses":5,"stiffness":40,"damping":5,"gain":0.9},"offset":[[0,0],[0,0],[0,0],[0,0]]}
```

- **slot** เรียงจากหลังไปหน้า: `skirt` `torso` `hood` `hairBack` `face` `hairFront` `glasses` `hat` ช่องละ 1 ชิ้น
  - `hood` กับ `hairBack` อยู่หลังตัวเมื่อหันหน้า และอยู่บนหลังเมื่อหันหลัง (ฮู้ดอยู่ใต้ผม)
- **tint** ย้อมเป็นสีอะไร: `hair` สีผม · `item` สีของ · `top` สีเสื้อ · `bottom` สีกางเกง · ไม่ใส่ = ใช้สีที่วาด
- **anchor** ขยับตามอะไร: `head` (ค่าเริ่มต้น) หรือ `waist`
- **blink** ภาพมี 3 แถว: ลืม / ครึ่ง / หลับ เกมกะพริบทุก 2–6 วินาที บางทีกะพริบซ้ำ 2 ครั้ง
- **sway** แถว = ท่าที่เอียงจากซ้ายสุดไปขวาสุด สปริงเลือกท่าจาก:
  - ความเร็วแนวนอนบนจอ ทำให้ลากไปด้านหลัง
  - จังหวะก้าว ทำให้เด้งเบา ๆ
  - ลม ซึ่งแรงขึ้นตอนฝนตก
- **offset** ตำแหน่งที่เลื่อนจากที่วาดไว้ แยกต่อทิศ ตั้งใน editor

| | ตอนนี้มี | วิธีทำ |

| ล่าง (`BOTTOMS`) | ขายาว · ขาสั้น · กระโปรง | ขาสั้นทาหน้าแข้งเป็นสีผิว · กระโปรง = ขาสั้น + ชิ้นซ้อน `skirt` (ติดเอว พลิ้ว) |

## Avatar editor (`?avatar=1`)

- แสดง 4 ทิศในท่ายืน กับตัวที่ 5 ที่เล่นท่า เวลาเล่นตัวนี้ยืนที่เดิม แต่ชิ้นที่พลิ้วจะรู้สึกเหมือนกำลังวิ่ง
- ใส่หรือถอดชิ้น ลากหรือกดลูกศรจัดตำแหน่งทีละทิศ คัดลอกค่าไปทิศกระจกได้
- ปรับสปริง (ความแข็ง ความหน่วง แรงขับ) และลองเสื้อผ้า สี ผิว ผม
- Ctrl+S บันทึกลง `shared/parts.json` ผ่าน server (`PUT /api/parts` ใช้ได้เฉพาะตอนพัฒนาและจากเครื่องนี้เท่านั้น) server ตรวจก่อนเขียน

| ชิ้นที่เปลี่ยนทรง (หมวก ผม กระโปรง ผ้าคลุม) | วาดภาพสีเทา 4 ทิศ × N แถว ลงใน `head/<id>.png` (ใช้ template จาก `head_parts.py` หรือดูตัวอย่างจาก `hair_part.py`/`cloth_part.py`) แล้วเพิ่มบรรทัดใน `parts.json` แล้วจัดตำแหน่งใน editor |

| ให้ผมที่วาดนิ่งพลิ้วได้ | `sway_poses.py head/<id>.png` (ตัวเลือก `--amount` = ปลายผมเลื่อนได้กี่ px) แล้วใส่ `sway` ใน `parts.json` ปรับความแข็ง/หน่วงใน editor |
| เสื้อออกแบบจาก AI | ChatGPT แต่งตัวให้ `hair_ref.png` (แก้แค่ลำตัวและแขน) → `top_from_ai.py <ภาพ> head/<id>.png` → เพิ่มใน `parts.json` (ให้เกมโหลดภาพ) และใน `TOPS` (`print` = id, `sleeveColors` = สีที่สคริปต์พิมพ์) · ลายลำตัวถูกตัดลงบนเสื้อของทุกเฟรม (เลื่อนตาม `shirt` ใน `player_body.json`) ไม่ได้แปะเป็นภาพนิ่ง จึงไม่หลุดตอนหายใจหรือเดิน · แขนทาสีทุกเฟรม · ไม่ทำกางเกงจาก AI เพราะขาก้าว |
| หน้าแบบใหม่ | วาดคิ้วตาบนหัวเปล่า 3 แถว (ลืม/ครึ่ง/หลับ) หรือเอาหน้าจาก Autosprite มาผ่าน `face_part.py` |
| ท่าใหม่ / ตัวฐานใหม่ | Autosprite → `char_sheet.py` → `blank_face.py` → `char_rig.py` → `body_regions.py` แล้วเสื้อผ้าทั้งหมดใส่ได้เอง (ชิ้นซ้อนอาจต้องปรับ offset) |

## ยังไม่ได้ทำ / ข้อจำกัด

- **ท่าเดินจริง:** ตอนนี้ตัวฐานมีแค่ท่า idle (ตอนเดินก็เล่นท่า idle) ต้องใช้เครดิต Autosprite ทำท่าเดิน 2 ชีต
- **ตัวฐานหญิง:** ยังไม่ได้ทำ ต้องหัวเท่ากับตัวชาย ชิ้นหัวจะได้ใช้ร่วมกัน
- **ภาพ:** ทรงผม กระโปรง และฮู้ด วาดด้วยโค้ดเพื่อทดสอบระบบเท่านั้น ของจริงต้องวาดมือหรือให้ AI วาดแล้วเกลา
- **กระโปรงทับมือ:** มือที่ห้อยข้างสะโพกถูกกระโปรงทับ เพราะแขนไม่ได้อยู่คนละชั้นกับตัว
- **ตาข้างไกลไม่กะพริบ:** ตาข้างที่อยู่ติดขอบหัวเป็นส่วนของเส้นขอบตัว จึงไม่กะพริบ (1–2 px)
- **เสื้อกล้ามและแจ็กเก็ตเปิดหน้า:** ยังไม่มี เพราะต้องหาแนวแขนเสื้อและแนวกลางลำตัวเพิ่มใน `body_regions.py`
- **ชิ้นซ้อนที่เป็นภาพนิ่ง (กระโปรง ฮู้ด):** ยังเลื่อนตามจุดยึดทั้งชิ้น ถ้าตอนเดินดูหลุด ต้องตัดลงทุกเฟรมแบบเดียวกับเสื้อ · ตอนนี้กระโปรงทับชายแจ็กเก็ต (เหมือนเหน็บเสื้อ)
- **เสื้อลายจาก AI ตอนเดิน:** ตัดตามเสื้อทุกเฟรมแล้ว แต่ถ้าตัวบิดมาก (ไม่ใช่แค่เลื่อน) ลายจะเพี้ยนเล็กน้อย ต้องดูกับชีตท่าเดินจริง
- **เอฟเฟกต์ชุด:** ยังไม่ได้ทำ (เรืองแสงกลางคืนใช้ระบบ glow ที่มีอยู่ได้ · ประกาย/อนุภาค)
- **หน้าสร้างตัวละครสำหรับผู้เล่น:** ยังไม่ได้ทำ (editor ตอนนี้เป็นเครื่องมือฝั่งทีม)
