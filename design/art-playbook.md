# Art Playbook · ทำภาพเมือง ตัวละคร แสง และเงาให้ได้ระดับ Night Camp

> **อ่านไฟล์นี้ทุกครั้งก่อนเริ่มงานภาพ แมพ ตัวละคร หรือแสง** (ทั้ง torad และ Claude)

## 0. สรุปในบรรทัดเดียว

**AI เป็นแค่วัตถุดิบ ส่วนความสม่ำเสมอมาจากกฎและโค้ด และความสวยมาจากแสง**
ไม่เจนฉากเป็นภาพเดียว ไม่เจนตัวละครทีละเฟรม ให้เจนเป็น "ชิ้น" ที่ผ่านกฎเดียวกันหมด แล้วให้เกมประกอบชิ้น จัดวาง ใส่แสง และใส่เงาเอง

## 1. Night Camp ใช้อะไรทำ (เท่าที่ยืนยันได้)

| ส่วน | เครื่องมือ | ระดับความมั่นใจ |
|---|---|---|
| เขียนโค้ดเกมและเครื่องมือ | **Claude + Codex** | ✅ เจ้าของบอกเองในโพสต์ (27 ก.ย. กลุ่ม OpenAI Codex) |
| ภาพต้นฉบับ | **GPT (ChatGPT image)** + วาดมือ | ✅ เจ้าของบอกเอง ("gpt", "art มือ") |
| เก็บงาน pixel art | **Aseprite** (เขาพิมพ์ว่า "aspire") | ✅ เห็นในคลิปแมพโรงงาน ทุก prop แยกเป็นไฟล์ `.aseprite` |
| ตัวละครแบบมีกระดูก | **Spine** + จัดกระดูกเอง | ✅ เจ้าของบอกเอง ("spine", "กระดูกจัดด้วยมือ") |
| ปั้นโมเดลหรือ normal map | **Blender** | ✅ อยู่ในรายชื่อเครื่องมือของเขา ส่วนเอาไปทำอะไรนั้นเดาเอา (น่าจะเป็น normal map หรือ reference มุมกล้อง) |
| เครื่องมือภายในที่เขียนเอง | Pose Studio (จัดท่าตัวละคร) · ตัววางแมพจาก seed · ตัวตรวจฐานอาคาร | ✅ เห็นในคลิป ทั้งหมดดูเป็นเว็บแอปที่ให้ Claude หรือ Codex เขียนขึ้น |
| ตัวเกม | **เกมบนเว็บ** ("เล่นเกมบนเว็บได้เลยฟรี play.nightcamp.app") | ✅ จากคำอธิบายคลิป CBT · เว็บข้อมูลเกมใช้ Next.js |
| เอนจินเกม | **ยังไม่รู้** | ❓ โดเมนปิดไปแล้วหลังจบ alpha และ Wayback ไม่ได้เก็บตัวเกมไว้ ดูจาก shader แสงในคลิป (`vec3 n = normalMap(uv)`) เป็น WebGL แน่ แต่จะเป็น Phaser, PixiJS หรือเขียนเองก็ยังยืนยันไม่ได้ |

> **สำหรับเรา:** Chill Town ใช้ **Phaser 4** (WebGL) อยู่แล้ว ซึ่งทำแบบเดียวกับเขาได้ทั้งหมด Phaser 4 มีระบบแสงใหม่ที่รองรับ normal map, self-shadow และ cone light (4.2) ในตัว และมี runtime ของ Spine สำหรับ Phaser 4 อย่างเป็นทางการ จึง**ไม่ต้องเปลี่ยนเอนจิน**

## 2. กฎของ asset (ทุกชิ้นต้องผ่านก่อนเข้าเกม)

ภาพจาก AI **ไม่มีทางเป็น true pixel art** เพราะภาพ 1024×1536 มีราว 139,000 สี เม็ดใหญ่ไม่เท่ากัน (~3.57×3.35) ไม่ตรงกริด และขอบเบลอ ถ้าย่อแบบเฉลี่ยสีจะขุ่น ถ้าย่อแบบเลือกจุดเดียวจะหยัก จึงต้องแปลงและตรวจทุกชิ้น

**4 ข้อต้องผ่าน** (ตรงกับ PROJECT_NOTES §3):
1. **มุมกล้องตรงเกม:** isometric 2:1
2. **ฐานลงกริด:** ความชันเส้นฐาน 0.5 ± 0.07 · เส้นฐานอยู่บนกริดอย่างน้อย 85% · ห้ามล้นฐาน ← *Night Camp ตรวจอัตโนมัติทุกหลังก่อนวาง เราควรทำเหมือนกัน*
3. **เม็ดพิกเซลเท่ากันทั้งเกม:** แปลงด้วย `tools/pixelfix.py --scale N` ค่าเดียวทั้งชุด
4. **สีเรียบ ขอบคม ชุดสีจำกัด:** ลดสีเข้า palette ห้ามมีไล่สีหรือเบลอ

**ตัวอย่างจริงจากคลิป:** เจนร้านสะดวกซื้อร้านเดียวกัน 4 แบบ มีแบบเดียวที่กลืนกับฉาก คือแบบที่มุม สไตล์ เม็ดพิกเซล และฐานตรงกันครบ
- แบบที่เจนตรงๆ ไม่ล็อกสไตล์ → มุมเพี้ยน
- แบบที่เจนตามสไตล์แล้วย่อ → เบลอ
- แบบที่เก็บรายละเอียด 2 เท่า → เม็ดเล็กกว่าของรอบข้าง

**ล็อกสไตล์ให้ทุกชิ้นตรงกัน:** เส้นขอบ · ทิศแสง (ของเรา: ซ้ายบน) · มุมมอง · ระดับรายละเอียด ถ้าไม่ล็อก วางลงแมพเดียวกันแล้วจะ "ดูหลุด"

## 3. ฉากและเมือง

### 3.1 ห้ามเจนแมพทั้งแผ่นเป็นภาพเดียว
- ซูมแล้วแตก (ทั้งแมพมีแค่ 1.6 ล้านพิกเซล เทียบกับ 20.8 ล้านของเขา)
- เกมไม่รู้ว่าจุดไหนเป็นต้นไม้ จุดไหนเป็นน้ำ จึงทำ collision และการบังตัวละครไม่ได้
- ไฟล์หนัก 35 MB ต่อแมพ (PNG 5200×4000)

### 3.2 วิธีที่ใช้: ชุดของ + ใบสั่ง + seed
1. **ชุดของประจำแมพ (kit):** เจนแยกเป็นชิ้น เช่น ป่าของเขามี 14 ชิ้น รวม 2.6 MB ทุกชิ้นล็อกสไตล์เดียวกัน
2. **ใบสั่งแมพเป็น JSON ขนาดประมาณ 2 KB:** `W, H, biome, roads[], ponds[], landmarks[], safe[], zones[], spawns[], warps[]`
3. **วางของด้วย seed:** วางเองเฉพาะจุดเด่น (11 ชิ้น) อีก 1,107 ชิ้นให้โค้ดวาง เปลี่ยน seed ก็ได้แมพใหม่ในเวลาไม่ถึงครึ่งวินาที
→ ของเรามี `shared/rooms/*.json` กับ map editor `?edit=1` อยู่แล้ว **ขาดแค่ส่วนกระจายของด้วย seed**

### 3.3 เมืองจริง (แมพเยาวราช) ← แบบที่ torad อยากได้
- **ผังจาก OpenStreetMap ของจริง:** ถนน 63 เส้น อาคาร 914 หลัง หมุนผัง −40° ให้ถนนหลักขนานกับกริด และหมุนแค่ครั้งเดียว ห้ามกลับด้าน
- ความกว้างถนนตามจริง (ประมาณ 10 ม. ต่อช่อง) · ซอยเรียงลำดับตามจริง
- **พื้นแบบกรุงเทพฯ:** ยางมะตอยเก่ามีรอยปะรอยแตก มีเส้นแบ่งเลน · ฟุตบาทกระเบื้องสี่เหลี่ยมฉายเป็น iso โดยรอยต่อเอียง 2:1 ตรงกับทุกเส้นในฉาก
- **อาคาร:** ทุกหลังเริ่มจากบล็อก 2:1 ที่ฐานลงกริดพอดี แล้วตรวจก่อนวาง (ดู §2 ข้อ 2) · มีแลนด์มาร์กจริง 6 แห่ง · ตึกแถว 15 แบบ ร้านติดกันห้ามซ้ำแบบ
- **ของบนถนน:** เสาไฟฟ้าสายพันกันแบบกรุงเทพฯ · โคมแดง · ไฟคนข้ามทุกทางม้าลาย · รถเข็น โต๊ะ เก้าอี้พลาสติก วางชิดหน้าร้าน ไม่ขวางทางเดิน
- **ชีวิตบนถนน:** รถวิ่งตามทิศเดินรถจริง (ทางเดียวก็ทางเดียว) เว้นระยะ หยุดรอไฟแดง · คน 10 แบบหาเส้นทางเอง ข้ามตามสัญญาณ ไม่เดินทับกัน
- เขาย้ำในโพสต์: **"อย่าลืมทำฐานกริดกันนะ"**

### 3.4 แมพโรงงาน (pixel art มือ + เจน)
- prop ทุกชิ้นแยกไฟล์ Aseprite ใช้ palette เล็กที่ล็อกไว้ (ประมาณ 16–24 สี)
- ประกอบเป็นเลเยอร์: `outside / yard / drive / puddles / pieces / generated`
- จบด้วยแสงไล่จากกลางวันเป็นกลางคืน และฝนตก

## 4. แสงและเงา (ส่วนที่ทำให้ "สวย")

ภาพทุกชิ้นวาดด้วย **แสงกลางวันแบนๆ** แล้วให้เกมใส่แสงเอง (เราใช้หลักนี้อยู่แล้ว: ห้ามอบแสงกลางคืนลงในภาพ)

**ลำดับชั้น** (ทั้งหมดใช้ประมาณ 4.5 ms ต่อเฟรม จากงบ 16.7 ms ที่ 60 fps):

| ชั้น | ทำอะไร | ได้มาจาก | ของเรามีหรือยัง |
|---|---|---|---|
| ภาพเดิม | สีกลางวัน | asset | ✅ |
| **normal map** + แสงแดด | ภาพแบนรับแสงเหมือนมีมิติ แดดหมุนตามเวลา เงาทอดตามมุมแดด | ภาพ normal map คู่กับ asset (ชมพู = หันขวา, ฟ้าอมเขียว = หันซ้าย, เขียว = หันขึ้น, ม่วง = หันเข้ากล้อง) | ❌ ใช้ระบบแสงของ Phaser 4 ได้เลย |
| เงา | เงาวัตถุบนพื้น | มุมแดด | ⚠️ มีเงากลางวันแบบง่าย |
| **emission map** | หน้าต่าง โคม ป้าย สว่างเอง ไม่โดนความมืดกด · `สีที่เห็น = max(สีหลังโดนแสง, สีเรืองแสง × ความแรง)` | ภาพเรืองแสงขนาดเท่าภาพเดิม 1 ภาพต่อชิ้น | ✅ คือ `_glow` จาก `tools/prep_asset.py` |
| ความแรงต่อชิ้น | ลดเฉพาะชิ้นที่แรงไป เช่น ร้านสะดวกซื้อเหลือ 40% | ค่า 0–100% ต่อ prop | ❌ |
| bloom | แสงฟุ้งรอบไฟ | พิกเซลที่เรืองแสง | ❌ |
| **พื้นเปียก** | ติดธงว่า tile ไหนสะท้อนได้ (ถนน ทางม้าลาย ทางเท้า ได้ · หญ้าไม่ได้) | ชนิดของพื้น | ❌ |
| เงาสะท้อน | เส้นแสงยาวใต้ไฟแต่ละดวง ระลอกตามฝน แรงขึ้นตามปริมาณฝน × ความมืด ฝนหยุดหรือกลางวันก็หายเอง | แหล่งไฟด้านบน + ฝน | ❌ |
| หมอก + ลำแสง | บรรยากาศ | — | ❌ |
| โทนสีตามเวลา | กลางคืน: เงาออกฟ้า แสงไฟออกส้ม | เวลาในเกม | ✅ (แสง 5 ช่วงเวลา) |
| ขอบภาพมืด (vignette) | ดึงสายตาเข้ากลางจอ | — | ❌ |
| DOF (tilt-shift) | ขอบบนกับล่างเบลอ ตรงกลางคม | — | ❌ |

## 5. ตัวละคร: ใช้ Rig + Bone ไม่วาดทีละเฟรม

**เหตุผล:** ถ้าเจนทีละเฟรม จะต้องใช้ 248 ท่า × 8 เฟรม × 144 ชุด = 285,696 ภาพ และหน้า สี ขนาด จะเพี้ยนไปทีละนิดทุกภาพ

**ขั้นตอน:**
1. **วาดแยกชิ้นบนพื้นชมพูบานเย็น** (สีที่ไม่มีในตัวละคร จะตัดพื้นออกได้เป๊ะ): หัว ลำตัว แขนหน้า แขนหลัง ขาหน้า ขาหลัง อาวุธ
2. **จุดหมุน (pivot) อยู่ที่ข้อต่อ** เช่น หัวไหล่ ถ้าตั้งผิดแขนจะหลุดออกจากตัว
3. **ลำดับชั้นจากหลังมาหน้า:** แขนหลัง → ขาหลัง → ขาหน้า → ลำตัว → อาวุธ → แขนหน้า → หัว
4. **กระดูกแบบพ่อ-ลูก:** ราก (สะโพก) → ลำตัว → หัว / ต้นแขน → ปลายแขน → อาวุธ / ต้นขา → หน้าแข้ง
5. **ข้อศอกงอแบบ Mesh** (แขนเป็นชิ้นเดียวแล้วงอ) ไม่ใช่ตัด 2 ท่อน จะได้ไม่มีรอยแตกตรงข้อ
6. **จัดท่าด้วยมุมกระดูก** แล้วตั้งคีย์เฟรมแค่ไม่กี่ท่า ให้เส้นโค้งทำหน้าที่เติมระหว่างคีย์: เส้นตรง / นุ่มเข้า-ออก / ระเบิด
7. **ท่าเดิน:** 8 ภาพต่อรอบ ขาสลับกัน งอเข่าตอนยกเท้า หัวโยกขึ้นลงนิดๆ **แขนแกว่งสวนขา** (ถ้าแกว่งตามขาจะดูเหมือนหุ่นยนต์)
8. **ท่าโจมตี:** ง้าง → ฟัน → ตามแรง → คืนท่า · **เฟรมที่โดน:** ให้ดาเมจ เสียง และเอฟเฟกต์เกิดในเฟรมเดียวกัน แล้วหยุดภาพสั้นๆ (hit-stop)
9. **ผสมท่าได้:** ขาเดินพร้อมแขนฟัน เพราะกระดูกแต่ละท่อนขยับแยกกัน
10. ผลลัพธ์ของเขา: **เสื้อผ้า 144 ชุด หมวก 148 ใบ อาวุธ 1,251 ชิ้น บนกระดูกชุดเดียว** หมวกติดกระดูกหัว อาวุธติดมือ ภายหลังเพิ่มกระดูกจาก 8 เป็น 34 ชิ้น (ผม `hair_T/B/F` ผ้าพันคอเป็นโซ่ แขนและขาอย่างละ 2 ท่อน)

**เทียบกับ Chill Town:** ตอนนี้เราใช้ sprite sheet ทีละเฟรมแบบ pixel art (ChatGPT/Autosprite → `walk_sheet.py`) และมีกฎว่า **"ห้ามหมุนพิกเซล"**
- Rig แบบ Night Camp ใช้ภาพสไตล์ HD chibi ซึ่งหมุนได้ แต่ถ้าหมุน pixel art ขอบจะแตก
- ทางเลือก: (ก) อยู่กับ sheet + ระบบแต่งตัวแบบ region map ที่มีอยู่ (ข) ใช้ rig แต่เรนเดอร์ท่าออกมาเป็นเฟรม pixel ล่วงหน้า (bake) (ค) เปลี่ยนตัวละครเป็นสไตล์ HD แล้วใช้ Spine จริง
- **ยังไม่ได้ตัดสินใจ** ต้องถาม torad ก่อนเปลี่ยนแนว

## 7. ทำ asset แบบไม่ต้องจ่ายค่า AI

## 9. แผนนำมาใช้กับ Chill Town (เรียงตามความคุ้ม)

1. **สคริปต์ตรวจ asset** (`tools/check_asset.py`): ความชันฐาน 0.5±0.07 · ฐานบนกริด ≥85% · ขนาดเม็ด · จำนวนสี → ไม่ผ่านก็ห้ามเข้าเกม
2. **ความแรงไฟต่อชิ้น + bloom** จาก `_glow` ที่มีอยู่แล้ว
3. **พื้นเปียก + เงาสะท้อน** (ธงต่อ tile ใน `shared/rooms/*.json`) ได้ผลมากเพราะเกมมีฝนอยู่แล้ว
4. **normal map + แสงแดดหมุนตามเวลา** ด้วยระบบแสงของ Phaser 4
5. **ตัวกระจายของด้วย seed** ใน map editor (ใบสั่ง JSON → วางของอัตโนมัติ)
6. **ผังเมืองจาก OpenStreetMap** สำหรับย่านสยาม (ใช้ผังจริงแต่ดัดแปลงชื่อและสีตามกฎเครื่องหมายการค้า)
7. ตัวละคร: ตัดสินใจเรื่อง rig กับ sheet (§5)
